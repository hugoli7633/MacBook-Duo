# 屏幕录制权限

启动时只检查屏幕录制权限，不再执行 tccutil 重置，也不在后台自动弹出授权请求。启用实时功能时由 ScreenCaptureKit 请求系统授权；控制界面的“屏幕录制权限设置”可打开对应系统页面。

首次成功启用后会记住后台启用状态。下一次启动，权限仍有效时自动恢复；权限不足时保持菜单栏白色图标，并提示从控制界面重新启用。登录后自动启动通过系统 SMAppService 登录项实现，可在控制界面或系统设置中关闭。

当前构建仍为 ad-hoc 本机签名。取消主动重置并不能保证跨构建无需重新授权，macOS 仍可能因签名变化要求重新确认。稳定分发应使用固定的开发者签名身份。
